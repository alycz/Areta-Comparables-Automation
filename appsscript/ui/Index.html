Comparables Automation

Workflow

Each step can run on its own. Step 05 runs the whole cycle in one go.

01

Import CIQ exports

Drop the Capital IQ "Financials" export for each company that has reported. Files are matched by ticker and reconciled to CIQ.

02

Review & apply

Check each proposed change against its CIQ source cell. Blocked values never reach the model; only blue input cells are written.

03

Refresh share prices

Runs automatically every Monday. Google Finance, cross-checked against a second source; last week's close becomes the prior price.

04

Check & report

Recalculates every formula independently, flags hardcodes, errors and outliers, then rebuilds the validation report with a dated PDF.

05

Run all steps

Steps 01 to 04 in order. Ready and Review items are applied; Blocked values are never written. Judgement items stay open for sign-off.
